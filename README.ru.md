fitTODOay — это платформа полного тренировочного цикла для тех, кому недостаточно статичного списка упражнений. Она объединяет планирование программ, проведение тренировки, надёжную фиксацию результатов, аналитику, AI-рекомендации, проверку техники и музыку в одном сфокусированном интерфейсе.

Вместо заметок, отдельных таймеров, таблиц, видео и чат-ботов fitTODOay собирает весь цикл обратной связи в одном месте:

> **Создать план → провести тренировку → сохранить результат → увидеть тенденцию → улучшить следующий день.**

## Почему fitTODOay выделяется

| Возможность                           | Что получает пользователь                                                                                                                       |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **AI-создание программ**              | Пошаговый помощник создаёт персональные программы на основе реального каталога, а backend проверяет каждое упражнение и тренировочный параметр. |
| **Гибкий редактор программ**          | Папки программ, расписание по дням недели, интервалам, циклам и конкретным датам, а также drag-and-drop сортировка.                             |
| **Режим тренировки без лишнего шума** | Дневной чеклист, запись каждого подхода, таймер упражнения и отдыха, статусы выполнения, звук и вибрация на поддерживаемых устройствах.         |
| **Offline-first учёт**                | Выполненные подходы и вес тела сохраняются локально при пропадании сети и автоматически синхронизируются после её восстановления.               |
| **Практичная аналитика**              | Нагрузка, прогресс упражнений, история веса и динамика программ превращаются в конкретные AI-выводы и следующие действия.                       |
| **AI-проверка техники**               | Короткое видео помогает определить упражнение и получить структурированный разбор: сильные стороны, ошибки и фокус на следующий подход.         |
| **Музыка внутри тренировки**          | Загрузка MP3 и 12 встроенных LIVE-радиопотоков: 10 энергичных станций для тренировки и 2 спокойных для восстановления.                          |
| **Интеграция OAuth MCP**              | Codex и совместимые AI-клиенты могут безопасно читать и изменять программы, тренировки, взвешивания и аналитику с явными `read`/`write` scopes. |

## Полный тренировочный цикл

### 1. Создайте план

Соберите программу вручную или попросите AI-помощника подготовить основу с учётом цели, опыта, оборудования, частоты и длительности тренировок. Модель использует только упражнения, существующие в каталоге fitTODOay.

### 2. Проведите сегодняшнюю тренировку

Активное расписание превращается в понятный дневной чеклист. Фиксируйте каждый подход, выполняйте упражнения по таймеру, отдыхайте с полноэкранным таймером и всегда видьте фактические значения.

### 3. Продолжайте даже без сети

Логи тренировки и взвешивания доступны offline. Ожидающие записи явно помечены и отправляются в фоне после восстановления подключения.

### 4. Поймите, что действительно изменилось

Аналитика показывает дневную нагрузку, прогресс упражнений, динамику программ и вес тела. AI выделяет значимые изменения и предлагает конкретные корректировки вместо общих мотивационных фраз.

### 5. Подключите тренировочные данные к AI-ассистенту

OAuth-защищённый MCP-сервер предоставляет специализированные инструменты, а не прямой доступ к базе данных. Авторизованный ассистент может искать упражнения, управлять программами, смотреть план дня, записывать подходы и вес, анализировать прогресс.

## Главные возможности

- **Более 870 упражнений** на русском и английском с мышцами, инструкциями, параметрами и изображениями.
- Системные и пользовательские упражнения с весовыми и временными режимами.
- Несколько программ, шаблоны дней, включение и отключение, комментарии и гибкие правила повторения.
- Фиксация каждого подхода с плановыми и фактическими значениями.
- Таймеры выполнения и отдыха, сохраняющие состояние в мобильном сценарии.
- Offline-очереди с защитой от дублей и автоматической повторной отправкой.
- Отдельный учёт веса тела, не смешанный с весами упражнений.
- Интерактивная аналитика по дням, упражнениям, программам и весу.
- AI-чаты по программам и аналитике с понятным просмотром предлагаемых изменений.
- Видеоразбор техники с фоновой обработкой, лимитами, сроком хранения и подтверждением упражнения.
- Глобальный музыкальный плеер: загрузка, очередь, shuffle, группировка, поиск и LIVE-радио.
- Безопасный OAuth MCP: хэширование токенов, rotation refresh-токенов, consent, отзыв доступа и scopes.
- Адаптивный интерфейс Next.js, светлая и тёмная темы.

## Архитектура

```text
Веб-приложение Next.js
    │
    ├── REST API ───────────────┐
    └── OAuth consent UI        │
                                ▼
                       Backend Django + DRF
                         │      │       │
                         │      │       └── OpenRouter: программы, аналитика, vision
                         │      └────────── PostgreSQL + pgvector
                         └───────────────── Redis + worker проверки техники

Codex / совместимый AI-клиент
    └── OAuth 2.0 + MCP ───────► инструменты fitTODOay с ограниченными scopes
```

В production приложение работает через Docker Compose и Caddy. Caddy завершает HTTPS и направляет веб-интерфейс, REST API, OAuth и MCP через единый публичный домен.

## Технологии

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, SWR, Zustand, Recharts, dnd-kit
- **Backend:** Django, Django REST Framework, PostgreSQL, pgvector, Redis
- **AI:** OpenRouter для создания программ, аналитических выводов и vision-разбора техники
- **Интеграция:** Streamable HTTP MCP с OAuth 2.0
- **Эксплуатация:** Docker Compose, Caddy, Let's Encrypt, фоновый worker проверки техники

## С чего начать

Для разработки рекомендуется Docker-first сценарий.

### Требования

- Docker Engine или Docker Desktop
- Docker Compose v2
- Git
- Ключ OpenRouter нужен только для AI-функций

### 1. Подготовьте окружение

```bash
cp .env.example .env
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env
```

Для локальной разработки замените пример Django secret и пароль администратора в `backend/.env`. Добавьте `OPENROUTER_API_KEY`, если хотите использовать AI-создание программ, аналитику и проверку техники.

### 2. Запустите приложение

```bash
docker compose up --build backend technique-worker frontend db redis
```

Или:

```bash
make up
```

### 3. Импортируйте каталог упражнений в новую базу

```bash
docker compose exec backend python manage.py import_exercise_db
```

### 4. Откройте fitTODOay

- Веб-приложение: [http://localhost:3000](http://localhost:3000)
- Backend и Django admin: [http://localhost:8000](http://localhost:8000)

При старте backend автоматически применяет миграции. Первый администратор Django создаётся из значений `DJANGO_SUPERUSER_*` в `backend/.env`.

## Проверки качества

```bash
make test-docker
```

Команда запускает backend-тесты в Docker и обязательный frontend lint. Перед релизом изменений frontend также выполните production-сборку:

```bash
cd frontend
npm run build
```

## Production

Не используйте команду разработки как инструкцию для production. Продакшен-контур использует заранее собранные образы, Caddy, автоматический TLS, закрытые служебные порты, постоянные volumes и явную настройку секретов.
