# Fittoday: тренировки через MCP

Работать с данными пользователя только через предметные tools подключённого OAuth MCP-сервера `fittoday`. Не использовать shell, прямые HTTP-запросы или пользовательские API-токены. Не просить пользователя присылать секреты; при ошибке OAuth предложить выбрать **Authenticate** у MCP `fittoday`.

## Рабочий процесс

1. Выбрать предметный tool по действию. Не передавать и не конструировать REST path, URL, HTTP method или заголовки.
2. Сначала найти или прочитать связанную сущность read tool. Не угадывать ID по названию.
3. Перед составлением программы получить профиль и учесть цель, доступное оборудование, опыт и ограничения здоровья.
4. Использовать только упражнения из каталога. Если нужного упражнения нет, явно предложить создать CustomExercise.
5. Преобразовать относительные даты в конкретные ISO-даты `YYYY-MM-DD`. Вес передавать decimal-строкой в килограммах, время и отдых — целыми секундами.
6. После записи перечитать результат подходящим read tool и сообщить точные изменённые значения.
7. Не повторять успешный POST после частичной ошибки. Для многообъектного создания сохранять и повторно использовать тот же `idempotency_key`.

## Подтверждать рискованные изменения

- Перед `create_training_program` показать пользователю структуру программы, дней и упражнений и получить явное подтверждение.
- Перед delete, каскадным удалением, полной перестановкой и потенциально массовым изменением показать точный scope и получить явное подтверждение.
- Одиночную безопасную запись, которую пользователь явно попросил выполнить, можно сделать без повторного вопроса.
- Для TemplateExercise всегда задавать ровно один источник: `exercise_id` или `custom_exercise_id`.

## Безопасность тренировок

- Не ставить медицинские диагнозы и не обещать безопасность тренировки.
- При боли, травме или противопоказаниях рекомендовать согласовать нагрузку со специалистом.
- Не обходить ограничения, указанные в профиле пользователя.
- В итоговом ответе явно указывать даты, единицы измерения и что именно было создано, изменено или удалено.
