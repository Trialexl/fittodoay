# fitTODOey — UX Outline

## 1. Guiding Principles
- **Быстрые действия:** все критичные операции доступны в 1–2 тапа/клика (отметить подход, переключить папку, скорректировать вес).
- **Четкость иерархии:** пользователь всегда видит, в какой папке/шаблоне работает, и откуда взято упражнение (системное vs кастомное).
- **Офлайн-дружественность:** действия, связанные с выполнением подходов и таймером, должны работать без сети и синхронизироваться позже.
- **Неперегруженность:** формы собирают только одну логическую группу данных за раз, подсказки убираются после заполнения.

## 2. Ключевые пользовательские потоки
1. **Onboarding профиля** — пользователь впервые после регистрации, проходит многошаговую форму с прогрессом.
2. **Управление программами/папками** — просмотр списка папок, переключение активности, drag&drop шаблонов.
3. **Редактор шаблона дня** — настройка расписания и списка упражнений на конкретный день/правило повторения.
4. **Ежедневный чеклист** — выполнение тренировки, отметки подходов, таймеры и корректировки по факту.
5. **История и аналитика** — просмотр агрегатов прогресса (по упражнениям и глобальной нагрузке).
6. **Создание кастомного упражнения** — отдельный поток, запускаемый из редактора шаблона или справочника.

## 3. Экранные схемы
### 3.1 Onboarding профиля
- **Шаги:** (1) цель и уровень → (2) биометрия (пол, возраст, вес, рост) → (3) оборудование и ограничения → (4) подтверждение.
- **Компоненты:** верхний прогресс-бар, секция подсказки «зачем нужны данные», primary CTA «Далее». Ошибки валидируются inline.
- **Состояния:** заполнено/незаполнено, возможность пропустить шаг? — нет, все поля обязательны.

### 3.2 Список программ
- **Layout:** карточки папок с названием, статусом (чип «Активна»/«Не активна»), комментарий, счетчик шаблонов.
- **Действия:**
  - Тоггл активности (требует подтверждения при отключении папки, отображается постфикс «- не активен» на карточке).
  - Drag&drop шаблонов внутри списка папок (режим редактирования).
  - Кнопка «Новая папка» (модалка: имя, комментарий, активность).
- **Пустые состояния:** «У вас пока только папка “Основные” — добавьте дополнительные для разных целей».

### 3.3 Редактор шаблона
- **Структура экрана:**
  1. Хедер с названием шаблона, папкой, флагом активности.
  2. Блок расписания: выбор дня недели, повторения (еженедельно, раз в N недель, раз в X дней, исключения).
  3. Список упражнений (карточки с порядком, названием, источником). Каждая карточка разворачивается в форму параметров.
  4. Панель действий: «Добавить упражнение» (открывает селектор каталога), «Создать кастомное упражнение», «Сохранить».
- **Упражнение в списке:**
  - Показывает источник (иконка каталог/кастом) и признак активных override (иконка карандаш).
  - Поля override: вес, повторы, подходы, время, отдых, заметка. Если поле пустое — подсказка «Используется значение по умолчанию: …».
  - Кнопки reorder (перетаскивание), копировать, удалить.
- **Селектор упражнений:** табы «Каталог» и «Мои». Поиск по названию/целевым мышцам, предпросмотр дефолтов, кнопка «Добавить в шаблон».

### 3.4 Ежедневный чеклист
- **Header:** дата, суммарная нагрузка за день (расчёт по формуле), селектор папки (при наличии нескольких активных).
- **Секции:** сгруппированы по папкам → шаблонам → упражнениям.
  - Каждое упражнение разворачивается в список подходов (кол-во строк = итоговое число сетов). В строке: чекбокс, вес, повторы/время, кнопка «корректировать». После отметки строка сереет, запускается таймер.
- **Таймер отдыха:** после отметки подхода вся поверхность экрана переходит в полноэкранный режим таймера (анимированный круг, карточка упражнения, кнопки «Пропустить», «Свернуть», «Рестарт»). При сворачивании появляется компактный индикатор, который можно вернуть в полный экран. Работает офлайн, при потере сети сохраняет события локально.
- **Офлайн индикатор:** статусная плашка вверху «Нет соединения — прогресс сохранится при синхронизации».

### 3.5 История и аналитика
- **Вкладки:** «По упражнениям», «По дням», «Рекомендации (AI)».
  - По упражнениям: список движений с трендом веса/повторов, выбор периода.
  - По дням: график глобальной нагрузки (сумма веса×повторы×подходы + эквивалент времени), фильтры по папкам.
  - Рекомендации (placeholder до AI-этапа): текстовые карточки «Повысить вес в жиме на 2.5 кг» (в будущем на основе логов).
- **Табличный режим:** для пользователей, кто хочет видеть детали — collapsible таблица с последними подходами.

### 3.6 Создание кастомного упражнения
- **Запуск:** кнопка на экране выбора упражнений или в разделе «Мои упражнения».
- **Форма:** название, целевые мышцы (чипы), флаги «есть вес» / «есть время», дефолтные вес/повторы/подходы/время/отдых, краткое описание.
- **Дополнительно:** поле «Основано на» (readonly, если стартовали из системного упражнения), чтобы сохранить связь.

## 4. Состояния и ошибки
- **Неактивные папки/шаблоны:** в чеклистах и списках всегда с постфиксом «- не активен» + визуальное обесцвечивание.
- **Конфликты расписаний:** если два шаблона пересекаются в одно время, подсвечиваем предупреждение «Несколько активных шаблонов на день — порядок определяется сортировкой».
- **Недоступность данных (офлайн):** действия выполняются локально, но рядом с чекбоксом появляется индикатор, пока событие не синхронизировано; таймер в полноэкранном режиме подсвечивает статус «Оффлайн» и хранит время локально.

## 5. Артефакты для дальнейшей работы
- Wireframes для каждого экрана (Figma / Excalidraw).
- UI kit: цветовые токены для активных/неактивных, компоненты карточек упражнений, таймер.
- Диаграмма состояний таймера отдыха.
- Прототип сценария «Добавление упражнения → создание кастомного → выполнение подхода».
