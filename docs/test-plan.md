# fitTODOay — E2E тест-план (MVP)

Цель: пройти ключевые пользовательские сценарии и убедиться, что фронт и бэкенд отрабатывают связно.

## 1. Онбординг и регистрация
1. Открыть `/onboarding`.
2. Заполнить шаги: email/пароль → биометрия → оборудование/ограничения.
3. Убедиться, что после завершения пользователь попадает на `/programs`, в localStorage сохранены `token` и `user`.

## 2. Управление папками и шаблонами
1. На `/programs` создать новую папку, проверить, что она отображается активной.
2. В конструкторе шаблонов выбрать папку, указать расписание (weekly), добавить упражнение из каталога, задать overrides.
3. Отправить форму и проверить в бэкенде (`/api/programs/templates/`), что шаблон создан, упражнение привязано.

## 3. Выполнение тренировки
1. Перейти на `/workout`, нажать «Обновить» — должен подтянуться план с приоритетом папки «Основные».
2. Отметить хотя бы один сет. Проверить, что:
   - Появился полноэкранный таймер.
   - В `/api/workouts/logs/` создалась запись.
   - После завершения всех сетов статус дня меняется на `completed`.
3. После выполнения всех сетов раскрыть папку и нажать «Рекомендации»:
   - запрос к `/api/workouts/recommendations/?date=…` возвращает блоки только по завершённым программам;
   - первое поле автоматически в фокусе, папка развёрнута;
   - ввод корректировок и кнопка «Применить» обновляют plan через `/api/workouts/recommendations/apply/` (повторы/вес изменились в шаблоне).

## 4. Аналитика и AI-feed
1. На `/analytics` проверить:
   - карточки «Нагрузка по дням» и «Топ упражнений» обновляются после выполнения подходов;
   - новый график «Динамика по программам» умеет переключать диапазоны (неделя/месяц/полгода/год), режимы «по программам»/«по упражнениям» и гранулярность «день/неделя».
2. Хит `/api/analytics/ai-feed/` — убедиться, что приходят последние логи для будущих рекомендаций.
3. Хит `/api/analytics/program-trends/?range=month&granularity=week` — сверить, что данные совпадают с графиком (те же значения и легенды).

## 5. Офлайн-режим
1. В DevTools → Network выставить `Offline`.
2. На `/workout` отметить сет: чекбокс должен подсветиться, а баннер сообщит, что синхронизация произойдет позже.
3. Вернуть сеть, нажать «Обновить» — данные синкнутся.
