# Плейлист, графики и настройки — 0.4.6-dev

Работа в `main`. По прямому запросу пользователя 22 ноября 2026 опубликован
[предварительный релиз 0.4.6-dev](https://github.com/Trialexl/fittodoay/releases/tag/android-v0.4.6-dev).
Загружен точный проверенный APK из коммита `2403cb3`; будущие промежуточные версии автоматически не публикуются.

## Изменения по замечаниям

| Замечание | Реализация |
|---|---|

| Обновление кнопкой | Material 3 `PullToRefreshBox` над прокручиваемыми разделами. Пункт «Обновить» в верхней панели удалён |
| Настройки в разных местах | Один вход «Настройки»; оформление, профиль, синхронизация, музыка, таймеры, подключения и обратная связь собраны в раскрываемые разделы. Отдельного диалога оформления больше нет |
| Первый плейлист и текущий трек | Папки по умолчанию; нормализация путей как в вебе, включая Windows-разделители. Состояние следует поздно загруженным настройкам. Текущая папка раскрывается, прокрутка ждёт измерения загруженного списка |
| Слишком большая шапка плейлиста | Одна строка управления; поиск по кнопке заменяет заголовок в той же строке и получает фокус. Возврат закрывает поиск и очищает запрос. У компактной стандартной панели убран отдельный высокий drag handle |
| Закреплённая загрузка музыки | «Добавить музыку» — последний элемент `LazyColumn` треков; вне прокручиваемого списка этой кнопки нет |
| Ползунок | Общий Material 3 Slider: дорожка 4 dp, бегунок 20 dp, область взаимодействия от 48 dp. Время отражает предварительную позицию во время перетаскивания; после отпускания позиция обновляется сразу |
| Прямоугольная подложка плеера | Плеер вынесен из `Scaffold.bottomBar` поверх содержимого. Скругление, Haze, полупрозрачный tint. У прокрутки и переноса фокуса учтена высота плавающей панели |
| Название текущего трека | Foundation `basicMarquee`, отдельная обрезаемая область, которая не заходит на кнопки; применяется и в плейлисте |
| Инфо в чеклисте | Иконка использует акцент общей темы |
| Перестановка упражнений | Reorderable в редакторе дня: перемещение за ручку, анимация, автопрокрутка края и действия доступности. До сохранения меняется только локальный порядок; отмена не меняет программу |
| Длинный топ | Первые пять упражнений; остальные раскрываются кнопкой с общим количеством |
| Параметры занимают больше графика | На графике только компактная строка и кнопка параметров; детализация, группировка, вид и программа находятся в Material 3 sheet |
| Жирные шрифты | Основной текст и небольшие подписи — Normal, заголовки — Medium; сняты локальные Bold/SemiBold в общих панелях и сводке. Ответы помощника имеют фон общей поверхности |

Явно сохранённый пользователем режим музыки «Все треки» не перезаписывается.
Выбор «По папкам» сохраняется существующим API настроек.

## Данные и API

Серверные модели, миграции и обработчики не менялись. Существующие поля
`music_group_by`, `filename`, профиль и сортировка упражнений уже есть в API.

Редактор дня использует `PATCH /api/programs/templates/{id}/`, затем, только при
изменении порядка, `POST /api/programs/template-exercises/reorder/` с `template`
и полным массивом `order`. Он закрывается после успешных записей. При ошибке
перестановки остаётся открытым и допускает повтор. Два запроса не образуют одну
серверную транзакцию: поля дня к этому моменту могут быть уже сохранены.

Период аналитики теперь применяется к сводкам, нагрузке, весу и топу, а не только
к динамике программ. Запросы первых трёх разделов используют одинаковые `start/end`,
динамика — соответствующий `range`. Для архива отдельно сохраняются агрегаты
упражнений по четырём периодам: срезать агрегат за всё время было бы неверно.
Смена периода/детализации очищает предыдущую динамику до получения подходящего ответа.

Для радара с более чем 31 датой используются средние по календарным месяцам;
это явно написано над графиком. Пропуски исключаются из среднего, настоящий ноль
учитывается. Дневные данные остальных видов графиков не заменяются месячными.

## Тестовая история

`tools/seed-analytics-fixture.py` работает только с отдельным аккаунтом
`android-cross-*@example.invalid`, использует существующий API и отказывается
работать с обычным адресом до авторизации. Секреты не выводятся в отчёт.

Добавлены 768 подходов и 122 взвешивания за 23.11.2025–21.11.2026.
Расширенный набор содержит три явно помеченные QA-программы, шесть дней и
18 ссылок на упражнения каталога. Ранее существовавшие программы и записи сохранены.
Повторный запуск читает записи и пропускает уже заполненные подходы/взвешивания;
POST после неопределённого сетевого результата автоматически не повторяется.

Контрольное чтение после UI-проверок за 365 дней подтвердило 145 дней с нагрузкой, 770 подходов,
123 взвешивания и 15 упражнений в серверном агрегате. Это синтетические данные
для проверки интерфейса, а не тренировочные рекомендации.

Запуск: `python tools/seed-analytics-fixture.py --expanded --apply`;
без `--apply` выполняется только предварительная проверка,
`--report-only` перечитывает фактические количества.

## Используемые компоненты

- [Material 3 PullToRefreshBox](https://developer.android.com/reference/kotlin/androidx/compose/material3/pulltorefresh/PullToRefreshBox.composable).
- [Haze 1.5.4](https://chrisbanes.github.io/haze/1.5.4/usage/), Apache 2.0, совместим с текущей связкой Kotlin/Compose. На Android до 12 используется предусмотренная библиотекой полупрозрачная подложка без blur.
- [Reorderable 2.5.1](https://github.com/Calvin-LL/Reorderable/tree/v2.5.1), Apache 2.0; жесты, перемещение и автопрокрутка принадлежат библиотеке.
- Foundation BringIntoViewSpec учитывает перекрытие плавающим плеером; вложенные горизонтальные списки сохраняют свою область прокрутки.
- [Media3: выбор поверхности](https://developer.android.com/media/media3/ui/surface): штатный `surface_type="texture_view"` для небольшого встроенного видео. Это избегает потери кадра SurfaceView после фона в Compose; высокая энергоэффективность и HDR SurfaceView этим выбором не подтверждаются.

Лицензии новых зависимостей включены в APK в `assets/licenses/`.
