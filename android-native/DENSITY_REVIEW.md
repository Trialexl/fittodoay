# Рабочая итерация: основной чеклист, плейлист и графики

Локальная версия — `0.4.1-dev`, `versionCode=7`, прежняя подпись.
Эти изменения идут после опубликованной 0.4.0. Промежуточный релиз не создаётся:
по решению пользователя незавершённые версии остаются локальными.

## Сверка с вебом

Веб проверен вживую при ширине 393 px: программа с раскрытым днём и подходами,
плейлист с выбранным треком и меню действий, график с подсказкой после нажатия.
Дополнительно проверена реализация `Checklist.tsx`, `design-v2.css`,
`ProgramTrendPanel.tsx`. Измерены заголовок программы (13 px) и строка плейлиста
с исполнителем (48 px, заголовок 14 px). Android сохраняет область нажатия и
масштабирование системного шрифта, вместо механического уменьшения всего экрана.

## Реализация

| Область | Изменение |
|---|---|
| Программа на главном экране | Компактный заголовок 13 sp, внешние отступы 10 dp, отделение заголовка линией, AI и редактирование справа |
| День программы | Счётчик подходов в одной строке с названием, мышцы под ним, переход к редактору дня |
| Упражнение и подходы | Номер упражнения, компактный заголовок и счётчик; плотные строки результата/плана с кнопкой изменения; вложенное сворачивание сохранено; выполненные упражнения и программы получают зелёное оформление |
| Редактирование | Программа, день и упражнение открывают существующие редакторы прямо из чеклиста после получения актуального объекта API |
| Плейлист | Список занимает остаток высоты панели, виртуализируется и открывается у текущего трека; компактные строки с исполнителем и выделением выбора |
| Воспроизведение | В открытой панели доступны предыдущий/следующий трек, пауза и перемотка; меню «Играть», «Следующим», «В очередь»; воспроизведение элемента очереди, очистка и перестановка |
| Поиск и клавиатура | При вводе скрываются второстепенные фильтры и добавление файлов, остаются результаты и основные кнопки проигрывания |
| Графики | Подсказка у точки с датой и значениями, горизонтальное ведение пальцем, повторный тап скрывает значение; вертикальный жест остаётся прокруткой страницы |
| Столбцы | Как в вебе: сумма каждой программы за период, а не группы ежедневных столбцов |
| Анимация | Появление за 700 мс при смене данных/вида: прорисовка линий, рост столбцов, раскрытие круговой/радара, проявление тепловой карты |

Числа в подсказке не сокращаются до «тысяч»; отсутствующая запись явно обозначена.
Подсказка показывает до четырёх серий; для остальных доступен выбор серии в
легенде. Подсказка рисуется без перехвата касаний: обычный Material Surface
[блокирует касания под собой](https://github.com/androidx/androidx/blob/androidx-main/compose/material3/material3/src/commonMain/kotlin/androidx/compose/material3/Surface.kt).

## Контракт данных

Схема БД, миграции и backend не меняются. Используются существующие GET-методы
`/api/programs/{folders,templates,template-exercises}/{id}/`, прежние редакторы
и их сохранение, аналитические серии, список/загрузка MP3. Очередь исполняется
существующим Media3-сервисом. Текущий элемент очереди берётся из реального `Media3.currentMediaItemIndex`,
поэтому повтор одного трека не выделяет сразу несколько строк. Новых полей БД, фиктивных данных в пользовательском
интерфейсе и серверных обходных решений нет.

## Проверки

Графики проверяются не только существованием Canvas: тест выбирает первую дату,
проводит до последней и проверяет текст подсказки; столбцы проверяются по суммам
6257/4797 для двух синтетических серий. Для анимации сохраняются промежуточный и
конечный кадры и проверяется изменение пикселей. Эти серии не являются данными
пользователя и не записываются в backend.

Сетевые сценарии используют только зарегистрированный синтетический QA-аккаунт.
Воспроизведение проверяется с загруженными тестовыми MP3, в том числе с открытой
клавиатурой на 360 dp. Снимки и результаты текущих прогонов хранятся в
`artifacts/density-*`; галерея — `artifacts/density-review/index.html`.

Полная сверка всех функций приложения и проверка на физическом устройстве
остаются отдельной незавершённой работой. Эта итерация не объявляется завершением
полного паритета и не публикуется как релиз.
