# Разбор и переработка экранов V2 — Android 0.4.0

Веб изучен вживую на 393 × 786: плейлист с длинным списком, главный экран с
отдельным виджетом мышц и измерением веса, окно упражнения с описанием и
статистикой, верх и нижняя часть аналитики. Дополнительно прочитаны
`frontend/src/app/design-v2.css`, `GlobalMusicPlayer.tsx`,
`ExerciseInfoModal.tsx`, `ProgramTrendPanel.tsx`.

## Реализованные изменения

| Область | Прежняя проблема | Реализация |
|---|---|---|
| Плейлист | Переход в длинный раздел настроек, все действия текстом в строке | Отдельный нативный bottom sheet: поиск, группировка, фильтр источника, строки с исполнителем, выделение активного трека, меню действий, очередь |
| Добавление музыки | Уход с текущего экрана | Выбор и загрузка одного/нескольких MP3 внутри плейлиста; прежние API, очередь и потоковое воспроизведение |
| Отдельный виджет мышц | Крупные подписи и стандартные индикаторы на всю ширину | Заголовок с раскрытием, строки «мышца → шкала → выполнено из всего», относительная длина плана, легенда, семантика прогресса |
| Плашки мышц | Горизонтальная лента, часть групп скрыта | Перенос плашек на следующие строки, как в вебе |
| Вес перед тренировкой | Тесное поле с плавающей подписью, громоздкая кнопка | Компактное поле и кнопка, адаптация под ширину/шрифт, десятичная запятая, переход сразу к графику веса |
| Информация об упражнении | Стандартный AlertDialog, вертикальная стопка всех изображений | Bottom sheet на телефоне / широкий диалог на планшете, закреплённый заголовок и вкладки, прокрутка описания, галерея с навигацией |
| Статистика упражнения | Простой рисунок, смешивание одноимённых упражнений из разных программ | Общие вкладки, метрика, оси, дата/значение точки; приоритет программы, из которой открыто упражнение, и подпись источника |
| Вес тела и аналитика | Разные графики и случайные отступы, слабые подписи | Общая система осей, форматирования, выбора точки и легенды для всех трёх мест |
| Семь видов диаграмм | Простые линии/прямоугольники без полноценного оформления | Линия, площадь, сложение, столбцы, тепловая карта, круговая диаграмма и радар; подписи, выделение, корректная геометрия слоёв и попадание в дату |
| Остальные формы | Стандартные длинные ленты FilterChip | Общие компактные переключатели с переносом строк; системные сообщения оформлены как нейтральная компактная панель |

Телефонные панели используют `ModalBottomSheet` Material 3 с нативным жестом
закрытия и обработкой системных отступов/клавиатуры. На планшете — диалог
ограниченной ширины с независимой прокруткой содержимого. На узком экране
контролы переносятся, вместо сжатия полей и подписей.

## Данные и границы изменения

Схема БД и backend не менялись. Используются существующие списки музыки, API
одиночной/пакетной загрузки, настройки группировки, аналитика и каталог упражнений.
Типы диаграмм сохранены. Статистика упражнения использует текущую программу,
как в вебе; при отсутствии совпадений — общий fallback. Средний вес учитывает
только реальные подходы с весом (`weight_sets > 0`). Нулевые значения остаются
нулевыми; отсутствующие точки интерполируются по прежнему контракту трендов.
Значение в подписи выбирается из фактической записи, без выдачи интерполяции за факт.
Ось веса использует локальный диапазон, столбцы/площадь/сложение — нулевую базу.
Число делений согласовано с шагом шкалы, сотые измерений не теряются в подписи.

## Визуальная проверка

`visual-snapshot` расширен: шесть разделов и анкета, открытые панели плейлиста,
поиск без результатов, форма добавления MP3, виджет мышц, ввод веса, описание и
статистика упражнения, график веса тела и все семь диаграмм. Проверяются светлая
и тёмная темы, телефон 360/393 dp и планшет 1067 dp.
Дополнительный прогон — 360 dp со шрифтом 130%. Кнопки создания и выбор программ
перестраиваются по вертикали, подписи нижней навигации переносятся без обрезания.

Снимки `design-*` и `reference-*` используют сохранённые ответы синтетического
QA-аккаунта. Отдельные `stress-*` используют две явно синтетические серии по
18 точек для проверки плотных графиков. Они не создают записи на сервере и
не являются доказательством сетевого сценария или реальных тренировочных данных.

Галерея: `artifacts/design-review/index.html`, 200 снимков. Финальные проверки:
54/54 JVM debug и release, 4/4 тренировочных сценария, четыре визуальных прогона
с обеими темами. Профильный сетевой прогон — 7/8 и отдельный успешный повтор
офлайн-веса после исправления подготовки даты. Результаты прогонов и дальнейшие
ограничения фиксируются в `RELEASE_CHECKS.md`. Установка на физический телефон
не заменяется проверкой эмулятора; полный функциональный паритет здесь не объявляется.
