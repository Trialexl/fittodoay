# Окна, ссылки на упражнения и перетаскивание — 0.4.8-dev

Локальная итерация в `main`. Публикация этой версии не запрошена.

## Поведение

- У модальных подложек общая непрозрачность 96%: чат, описание упражнения,
  редакторы, календарь, подтверждения, панели графиков и выпадающие меню.
  У экранов отдыха/выполнения и свёрнутого таймера — 94%. Прозрачность
  применяется к цвету поверхности; текст, поля и кнопки не становятся бледными.
- Мини-плеер монтируется только на чеклисте (`Screen.Workout`). Музыкальная
  сессия Media3 продолжает работать при смене вкладки. Свёрнутый таймер
  остаётся доступным, пока идёт подход или отдых.
- Названия упражнений в ответе помощника — встроенные ссылки Compose
  `LinkAnnotation.Clickable`. Нажатие открывает тот же `ExerciseInfo` с описанием,
  изображениями и статистикой, который используется на чеклисте и в программах.
  Сохраняется контекст программы для статистики.
- Отправка в чате — стандартная Material 3 кнопка с иконкой самолётика вместо
  надписи. Для озвучивания остаётся «Отправить»; Enter, клавиатурная отправка
  и условия доступности кнопки сохранены.
- Распознавание названий соответствует подходу веб-компонента
  `ExerciseMentionText`: регистр, ё/е, разделители, русское/английское название,
  доменные алиасы и приоритет длинного совпадения. Части слов не превращаются
  в ссылки. Сообщения пользователя остаются обычным текстом.
- В раскрытом дне программы кнопки «Переместить выше/ниже» заменены
  `ReorderableColumn`. Изменение отображается сразу, сохраняется существующим
  `/api/programs/template-exercises/reorder/`; при отказе API откатывается
  затронутый день. Отмена запроса другого аккаунта не восстанавливает старые данные.
- В очереди музыки вместо «Выше/Ниже» — ручки Reorderable. На длинной очереди
  используется `ReorderableItem` в LazyColumn с прокруткой у края. Перестановкой
  медиасессии владеет Media3; текущий трек продолжает воспроизводиться.
  Редактор дня сохраняет уже существующее перетаскивание.

## Контракт и ограничения

Backend, БД и API не менялись. Ссылки используют каталог/свои упражнения из
контекста выбранной программы и открывают существующие endpoint описания и
аналитики. Произвольные упоминания неизвестных упражнений не создают фиктивные
карточки. Для недоступной техники/статистики остаются существующие ошибки и повтор.

Для жестов используется закреплённый Reorderable 2.5.1; интеграция сверена с
[документацией этой версии](https://github.com/Calvin-LL/Reorderable/blob/v2.5.1/README.md).
Собственный движок жестов или рисования ссылок не добавлялся.

Итоги проверок и путь APK — в [RELEASE_CHECKS.md](RELEASE_CHECKS.md).
Полная сверка всех экранов с вебом и физический телефон остаются вне этой итерации.
