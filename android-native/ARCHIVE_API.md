# Полная локальная копия: дополнительные вызовы 0.3.0

Реализовано в исходниках. На trialexl4.freemyip.com изменения не развёрнуты:
пользователь отдельно отложил обновление сервера и публикацию релиза.
Изменений модели и миграций не требуется.

## Контракты

- `GET /api/llm-agent/threads/`: только диалоги текущего пользователя, включая
  закрытые. Необязательный `program_id` — положительное целое; неверный формат
  возвращает 400. POST по этому адресу продолжает создавать новый диалог.
- Список диалогов: `{items, next, previous}`; `limit` по умолчанию 50, максимум 100.
  Курсор использует стабильный порядок по убыванию ID. Ссылки относительные,
  чтобы HTTPS-прокси не менял адрес следующего запроса на HTTP.
- Android обходит все страницы, затем читает
  `GET /api/llm-agent/threads/<id>/messages/` для каждого диалога.
  В чате программы доступен выбор сохранённых диалогов, включая офлайн.
- `GET /api/technique-reviews/`: прежнее поле `items`, дополнительно `next` и
  `previous`. Первая страница по-прежнему содержит до 20 проверок; остальные
  доступны через курсор. Android загружает все страницы.
- Проверка техники содержит `video_url`: относительный адрес
  `/api/technique-reviews/<id>/video/`, либо null при отсутствии исходника.
  GET требует обычной авторизации и проверяет владельца. Чужая проверка или
  отсутствующий файл возвращают 404; поддержаны Range / 206 / 416.
- Android сохраняет исходник в приватные постоянные файлы аккаунта. Уже
  сохранённые оригиналы повторно не скачиваются. «Смотреть видео» открывает
  нативный плеер и работает офлайн. После удаления проверки удаляется и файл.
- `/api/exercises/custom/` уже вызывается Android; локальная правка порядка
  маршрутов устраняет перехват слова `custom` маршрутом каталожного упражнения.

## Надёжность

Полная копия архива заменяется после успешного получения всех страниц.
При временном сбое используется предыдущая завершённая копия. Внешние адреса,
переходы на другой маршрут и циклы пагинации отклоняются до отправки токена.
Видео принимаются только по предусмотренному относительному маршруту текущего
сервера с HTTPS, без перенаправлений и с MIME video. Музыка не копируется.

Старый сервер может отвечать 404/405 на список диалогов: открытие уже известного
чата продолжает работать, а полная синхронизация честно остаётся неполной.
Для получения ещё неизвестных диалогов и серверных оригиналов потребуется
отдельное обновление сервера. Локальные тесты не означают развёртывание.

## Проверки

- Docker: архив диалогов, сохранённые сообщения, изоляция пользователей,
  сохранение POST-контракта, пагинация более 20 видео, скачивание байтов,
  Range, отсутствующий и удалённый файл.
- JVM: обход страниц, запрет внешних ссылок/циклов, сохранение полной копии
  после сбоя второй страницы и чтение всех страниц офлайн.
- Android: настоящее HTTPS-скачивание тестового видео с отдельным тестовым CA,
  совпадение байтов, повторное открытие хранилища, декодирование видео,
  отсутствие повторного запроса, изоляция аккаунтов и удаление файла.
- V2 UI: старый диалог из списка и нативный просмотр видео после завершения
  процесса приложения при выключенных Wi-Fi и мобильных данных.
