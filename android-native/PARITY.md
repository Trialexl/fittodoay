# Сверка Android и веба

Сервер: https://trialexl4.freemyip.com/. Нативный Kotlin / Compose, без WebView.
Основа: origin/main, c8a2d05. Ветка: codex/android-native. Проверки работают только с синтетическими аккаунтами.

## UI-итерация 20.11.2026

Доработаны общие компоненты Material 3, адаптивная навигация, восстановление
состояния вкладок и отображение целей упражнений в программах. Схема БД и API
прежние. Проверки и актуальная галерея: [VISUAL_REVIEW.md](VISUAL_REVIEW.md).
Это проверка нативного интерфейса; полный сетевой паритет остаётся незавершённым.

  Это реальные сохранённые ответы API, с отключённой сетью, без записи на сервер.

В ходе свежей сверки V2 анкета Android приведена к четырём веб-шагам: основная

При подготовке QA-данных явно учитываются расписание общей программы и UTC-диапазон
серверной аналитики. Историческая нагрузка для графиков создаётся через API только
синтетического аккаунта; текущая тренировка проверяется отдельно через нативный UI.

## Повторяемые проверки

Из android-native:

- ./tools/android.ps1 test — сборка, JVM, lint, обычные тесты устройства.
- ./tools/android.ps1 live-test — базовый сценарий синтетического аккаунта на сервере.
- ./tools/android.ps1 full-test — закрытые сценарии; несовместимый сервер не пропускается.
- ./tools/android.ps1 lifecycle-test — отдельные процессы подготовки и проверки после реального завершения процесса.
- ./tools/android.ps1 layout-test — маршруты, календарь и графики на компактном телефоне и планшете.

Для full-test используется %LOCALAPPDATA%/fitTODOay/cross-client-qa.json
с полями email, password, expectedWeight. Файл вне репозитория и не включается в отчёты.
Пароли и токены не печатаются в отчётах. Существующая пользовательская сессия не заменяется без QA-маркера.
Артефакты: artifacts/files/extended-parity/, artifacts/files/parity-artifacts/, artifacts/live/.
