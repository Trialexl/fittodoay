# Готовые компоненты Android

Правило пользователя: в спорных случаях выбирать готовые библиотеки и стандартные
компоненты; оформление принимать после проверки реального приложения.
Правило для последующих изменений — [AGENTS.md](AGENTS.md).

| Область | Используемая основа | Код приложения |
|---|---|---|
| Линии, площади, накопление, столбцы | Vico Compose M3 2.1.3 | Даты, интерполяция, суммы за период, исходные значения подсказки и тема |
| Круговая диаграмма, радар | KoalaPlot 0.8.0 | Данные, цвета, обработка выбора готового сегмента/символа |
| Тепловая карта | Compose Foundation LazyHorizontalGrid + Material 3 Surface | Матрица записей, насыщенность ячеек, выбор и пропуски; горизонтальная прокрутка библиотеки |
| Изображения техники | Foundation HorizontalPager + Coil | URL, кеш изображений, счётчик и доступные кнопки перехода |
| Плейлист и очередь | Foundation LazyColumn + Material 3 | Порядок, поиск, действия API, выбранный трек |
| Аудио | Media3 ExoPlayer / MediaSession | Сессия, авторизация, очередь и восстановление |
| Сигналы таймеров | Android NotificationChannel / SystemUI audio focus; AudioFocusRequest + MediaPlayer при запрете уведомлений | Короткий ресурс из двух сигналов, восстановление громкости и очистка состояния |
| Перемотка | Material 3 Slider | Тонкое оформление дорожки, позиция Media3 |
| Панели, диалоги, вкладки, поля, меню | Material 3 | Тема и бизнес-действия |

Vico отвечает за раскладку осей, кривые, координаты маркеров, их отрисовку и анимацию.
В адаптере стандартные `detectTapGestures` / `detectHorizontalDragGestures` Compose
закрепляют ближайший маркер Vico после отпускания пальца: штатная подсказка этой
версии библиотеки видна только во время нажатия. Сопоставление использует готовые
`layer.markerTargets`, без вычисления координат по шкале или датам.
На радаре выбор использует центры размещённых библиотекой символов. Это устраняет
перекрытие сенсорных областей соседних точек разных серий; клавиатура/TalkBack
вызывают то же действие через стандартную семантику Compose.
Накопленные области передаются в обратном порядке с непрозрачным заполнением,
чтобы нижние серии образовывали границы слоёв. Подсказка показывает исходные
записи, а не накопленную или интерполированную величину.
В столбцах одна серия из сумм программ за период; цвет привязан к программе.
Нули сохраняются, отсутствие записи не превращается в выполненную нагрузку.

Тепловая карта использует готовую прокручиваемую сетку, поскольку совместимая
версия KoalaPlot не содержит специализированной heatmap. Собственного Canvas,
геометрии попадания и обработчика жестов в ней нет. Дата и название серии доступны
при выборе ячейки; пустая запись отличается от нулевой.

Версии закреплены под текущую связку Kotlin 2.1 / Compose BOM 2025.05.01 / SDK 35.
Это совместимые версии, а не заявление об использовании последних выпусков.
Vico распространяется по Apache 2.0, KoalaPlot — MIT. Тексты лицензий включены
в APK в `assets/licenses/`.

## Следующие спорные компоненты

Календарь тренировок остаётся отдельной задачей сверки. Перед его переработкой
проверять Kizitonwose Calendar Compose: нужны собственные отметки нагрузки по дням,
обычный DatePicker не покрывает этот сценарий. Новую зависимость пока не добавляли.

Циферблат тренировки воспроизводит специфическое оформление веб V2. Его Canvas
рисует декоративные деления и кольцо; состояние таймера, фоновые уведомления,
диалоги и управление выполняют существующие Android/Compose компоненты.
Заменять визуальное оформление можно после проверки совпадения с веб-сценарием.

Наличие готовой библиотеки не означает завершённую сверку всего приложения.
Незавершённый релиз не публикуется; рабочие APK и снимки остаются локальными.
