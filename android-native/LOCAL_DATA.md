# Локальные данные Android 0.3.0

Согласованный объём: постоянная локальная копия и просмотр без интернета.
Создание и редактирование программ, дней и профиля требуют сервера. Существующая
очередь офлайн-подходов и взвешиваний сохранена. Активный интерфейс проверки — V2.

## Какие данные сохраняются

- Профиль, настройки оформления, программы, дни, упражнения и их параметры.
- Полный доступный каталог упражнений, описания, изображения и собственные упражнения,
  которые сервер отдаёт через API.
- Подходы, взвешивания, история нагрузки, планы выполненных тренировок и открытых дат,
  аналитика и все доступные варианты периодов/группировки графиков.
- Известные приложению чаты программ, сообщения, черновики, ответы анкеты и preview плана.
- Результаты проверки техники; оригиналы новых видео сохраняются до отправки на сервер,
  поэтому удаление временного файла загрузки их не уничтожает.

Музыкальные файлы не загружаются в локальную копию. Музыка продолжает передаваться
потоком; настройки и очередь плеера сохраняются прежним механизмом.

## Поведение

Первое получение данных требует подключения. После входа и запуска приложение
автоматически дополняет копию, включая ещё не открытые разделы и картинки каталога.
Файлы не помещаются в удаляемый кэш и не вытесняются по сроку или размеру.
Перезапуск продолжает загрузку по уже существующим файлам. Временные ошибки сети
повторяются с задержкой; отсутствие маршрута или свободного места не выдаётся за успех.
В профиле есть состояние загрузки, объём файлов, обновление и пауза.

При отсутствии сети разделы читают сохранённые данные. Для ещё не загруженной даты
показывается сообщение о первой загрузке; предыдущий план не остаётся под новой датой.
Отклонение preview также удаляет его локальную активную копию. После успешного
удаления проверки техники её локальный оригинал видео удаляется вместе с привязкой.

Данные находятся в приватном каталоге приложения и SQLite, отдельно для каждого
аккаунта. Выход очищает данные предыдущего аккаунта из состояния экранов; его
отдельная локальная копия остаётся для следующего входа. Пароль и ответы входа в эту базу не попадают. Токен остаётся в прежнем
хранилище Android Keystore. Резервное копирование приложения в Android отключено.

## Дополнительные вызовы 0.3.0

Реализованы перечисление всех диалогов, полная история проверок техники и
скачивание прежних оригиналов видео. Android сохраняет их и предоставляет
выбор диалога и нативный просмотр видео офлайн. Контракты и проверки:
[ARCHIVE_API.md](ARCHIVE_API.md). Изменения пока не развёрнуты на сервере.

## Границы текущего сервера

Отдельный маршрут полного списка `/api/exercises/custom/` возвращает 404.
Веб-клиент его не использует: добавленные свои упражнения приходят вложенными
в программы (`custom_exercise`). Android получает и сохраняет эти данные тем же
способом. Ошибка отдельного списка не означает запрет данных для Android.
Исправление маршрута и GitHub-релиз отложены пользователем.

Оба клиента читают сообщения чата по его ID. Веб получает ID при создании диалога;
отдельного API перечисления всех прежних диалогов нет для обоих клиентов. Android
сохраняет известные ему ID и переписку. Ограничение касается обнаружения старых ID.

Оба клиента получают результаты проверки техники и имя видеофайла. Текущий API
не возвращает ссылку на скачивание оригинала; веб-экран также не запрашивает исходное
видео. Результаты доступны Android так же, как вебу; новые Android-видео дополнительно
сохраняются локально. Отдельного ограничения доступа по типу клиента здесь нет.
Генерация нового ответа AI и новый анализ видео выполняются сервером и требуют сети.

## Проверки

- `./tools/android.ps1 local-data-test`: база, разделение аккаунтов, исключение музыки
  и входа, сохранение/удаление видео, все 6 разделов V2, чат и черновик после реального
  завершения процесса с выключенными Wi-Fi и мобильными данными.
- Проверяется восстановление preview и его явное отклонение; незагруженная будущая
  дата не показывает прежнюю тренировку; кнопка обновления без сети объясняет причину.
- `LocalDataPolicyTest`: сохранение API, обновление копии, offline lookup, ошибки
  401/403/404, временный 503, локальный поиск, фильтры дат и повтор временных ошибок.
- `LocalDataLiveTest`: реальные данные отдельного QA-аккаунта и настоящий файл картинки;
  отчёт содержит число упражнений и сохранённых изображений, без паролей и токенов.

Артефакты: `artifacts/local-data-*.txt`, `files/extended-parity/local-data-*.json`,
`files/extended-parity/local-data-*.png`. Успех этих проверок не заменяет полный
серверный прогон всех функций приложения.
