# Рабочая итерация: библиотеки графиков и сигналы таймеров

Локальная версия `0.4.2-dev`, `versionCode=8`, общая ветка `main`.
Промежуточный релиз не публикуется. Backend, API и база данных не изменялись.
Выбор компонентов и правила следующих правок: [UI_COMPONENTS.md](UI_COMPONENTS.md)
и [AGENTS.md](AGENTS.md).

## Что изменилось

| Область | Реализация |
|---|---|
| Линии, площади, накопление, столбцы | Vico Compose M3: оси, сетка, сглаживание, заливка, точки, анимация, готовые маркеры |
| Круговая диаграмма и радар | KoalaPlot: построение и анимация, выбор сегментов и точек |
| Выбор значений | Короткий тап закрепляет подсказку Vico; горизонтальное ведение выбирает ближайшую дату. Значения также доступны текстом под диаграммой |
| Данные | Суммы столбцов за период; нули сохраняются; пропуски интерполируются только для линии, в подсказке остаётся «Нет записи»; исходные значения в накопленной диаграмме |
| Единичное измерение | Точка располагается в центре, шкала веса тела учитывает фактический диапазон |
| Радар | Выбор ближайшего центра символа, размещённого библиотекой; соседняя серия не перехватывает тап из-за перекрывающихся областей нажатия |
| Тепловая карта | Готовая LazyHorizontalGrid с горизонтальной прокруткой; отдельные состояния отсутствия записи и нуля |
| Оформление | Общая палитра и типографика, спокойная сетка, меньше вложенных рамок, легенда только для нескольких серий |
| Галерея техники | Compose HorizontalPager: свайпы, счётчик и кнопки перехода, существующий кеш Coil |
| Сигнал таймера | Два звуковых импульса с параметрами веб-версии; длительность ресурса 1,2 с с учётом окна восстановления громкости |
| Приглушение музыки | Штатный звук NotificationChannel: SystemUI запрашивает временный audio focus и снимает приглушение после сигнала, включая свёрнутое приложение |
| Запрет уведомлений | При открытом приложении MediaPlayer и AudioFocusRequest воспроизводят тот же ресурс и освобождают focus после завершения/ошибки |
| Завершение и отмена | Автоматическая очистка состояния не удаляет звучащее уведомление; отмена до завершения и выход из аккаунта очищают уведомления |

Самописного Canvas-движка диаграмм больше нет. Адаптер использует готовые
координаты маркеров Vico и размещённые KoalaPlot символы. Compose Foundation
обрабатывает тап, горизонтальное ведение, прокрутку и свайпы галереи.
Лицензии Vico (Apache 2.0) и KoalaPlot (MIT) включены в APK.

## Ограничения

Полная сверка всех экранов с вебом ещё не завершена, календарь пока остаётся
прежним компонентом. Проверки выполнены на эмуляторе, физический телефон не
проверен. Аудиопроверка подтверждает реальное состояние Android/Media3;
акустическое прослушивание на физическом устройстве не проводилось.

В фоне звуковые уведомления зависят от разрешения уведомлений, настроек канала,
режима «Не беспокоить» и доступа к точным таймерам. Приложение уважает выключенный
пользователем звук канала. При запрете уведомлений foreground fallback доступен,
пока Android разрешает приложению получить audio focus. Глобальная громкость
устройства и сохранённая громкость плейлиста не изменяются. Процент приглушения
определяет Android/Media3; фиксированные 35% веб-плеера не навязываются системе.

Механизм: [Android audio focus](https://developer.android.com/media/optimize/audio-focus),
[SystemUI NotificationPlayer](https://android.googlesource.com/platform/frameworks/base/+/master/packages/SystemUI/src/com/android/systemui/media/NotificationPlayer.java).
Подписанный APK проверяется установкой и запуском; предметные UI-сценарии выше
выполнялись инструментированными debug-тестами, а не авторизованной release-сессией.
