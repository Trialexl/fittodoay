## Что работает

Данные доступных разделов и файлы сохраняются в приватном постоянном хранилище,
отдельно для аккаунтов. Офлайн-просмотр проверен с выключенными Wi-Fi и мобильными
данными после завершения процесса приложения. Музыкальные файлы остаются потоковыми.
Для первой загрузки требуется сеть. Состояние копии, обновление и пауза доступны в профиле.
Уже загруженные изображения используются повторно; временные ошибки повторяются.
Существующая очередь подходов и взвешиваний сохранена. Создание/редактирование
программ и профиля офлайн не добавлялось, согласно уточнению пользователя.

В полном копировании QA-данных осталось одно недоступное место:
`/api/exercises/custom/` возвращает 404. Статус честно остаётся неполным;
серверный фикс не развёрнут. Каталог и все 1746 его изображений сохранены.

Эти ограничения одинаковы для веба и Android. Свои упражнения в программах
приходят обоим клиентам вложенными в шаблоны; веб не обращается к отдельному
списку custom. Сообщения читаются обоими клиентами по известному ID диалога.
Не хватает перечисления прежних ID и ссылки для скачивания оригинального видео. Доступные результаты техники, известные Android
чаты и новые Android-видео сохраняются. Подробности: [LOCAL_DATA.md](LOCAL_DATA.md).
